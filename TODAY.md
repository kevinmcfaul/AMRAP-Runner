# Tempo Base

**2026-11-27**. 20 minute AMRAP, Easing back phase, light day.

_Base, week 2 of 4. Build the foundation: clean form, single-leg and stability work, lighter loads, no power sets yet._

- Light day: a key run is coming up, so today skips jumping and trims the volume.

Work through the list in order with no planned rest, then start again. Count rounds and reps until the clock hits zero.

1. **5 reps each side** Lateral lunge (single-leg). Sit back into the working hip, other leg straight, chest up.
2. **7 reps** Prone Y-T raise. Face down, lift the arms into a Y then a T. Thumbs up.
3. **7 reps** Reverse crunch (core). Curl the hips off the floor, no swinging.
4. **15 sec** Wall sit. Thighs parallel, back flat against the wall, breathe.
5. **17 reps** Step jack. Jumping-jack arms, but step each foot out instead of jumping.

One round takes about 2:22, so aim for roughly 7 rounds. That is 41 reps per round (holds not counted).
